# FAT CHANCE / あぶらあつめ

ラーメンのスープに浮いた油を、箸で寄せてひとつにまとめるブラウザゲームです。制限時間 60 秒のスコアアタック形式です。油の動きは流体対応の物理エンジン LiquidFun（Box2D に流体パーティクルを加えたもの）で計算しています。

## 動かし方

ビルドや依存パッケージのインストールは不要です。`index.html` をブラウザで開けば遊べます。物理エンジンを `vendor/liquidfun/` から読み込むので、`index.html` と `vendor` フォルダは同じ場所に置いてください。

ローカルサーバー経由で開く場合は、リポジトリ直下で次のコマンドを実行し、`http://localhost:8765` にアクセスします。

```bash
python3 -m http.server 8765
```

MAMP の htdocs 配下に置いているので、MAMP を起動している場合はそのまま MAMP の URL からも開けます。Claude Code の desktop アプリでは `.claude/launch.json` の `abura` 設定で同じサーバーを起動できます。

### 動作環境

- WebAssembly と WebGL2 に対応したブラウザ（最新の Chrome / Safari / Firefox / Edge）
- WebGL2 が使えない環境では Canvas 2D の簡易描画に切り替わります
- PC（マウス・キーボード）とスマートフォン（タッチ）の両方に対応
- フォント（Archivo Black）は Google Fonts から読み込みます。オフラインでは代替フォントで表示されます

### ルール

- 箸で油を押して寄せます。油どうしが触れるとくっついて大きくなります。離れた油が勝手に引き合うことはありません
- 得点は「終了したときに、いちばん大きい油の面積（mm²）」です。小さい油がいくつあっても点は伸びません。プレイ中の SCORE も「いま、いちばん大きい油の面積」を表示し、油が割れたりすくわれたりすると減ります
- 箸はゆっくり動かします。速く動かしている間は箸がスープから浮き、油に触れません（素早い移動は「持ち上げて運ぶ」扱いです）。浮いている間は箸の影が離れ、色が薄くなります
- 勢いをつけて押すと油がちぎれます
- ネギ・メンマ・麺の端はスープに浮かぶ障害物です。箸で押してどかせます
- 赤い油を 8 粒以上の油に取り込むと、その油が 2 倍にふくらみます。金色の油を取り込むと残り時間が 3 秒増えます
- 大きな油ができるとレンゲがすくいに来ます。WARNING と赤い円が出たら、いちばん大きい油を円の外へ押し出してください。円は予告が出た位置から動きません。円の中に残った分だけすくわれ、その分だけ点数が減ります。避けても加点はありません。残り 7 秒を切ると新しい予告は出ません
- START を押すと READY → GO の合図が出て、GO から時間が進みます
- ウィンドウやタブから離れると自動で一時停止します

### スコア

最終スコアは、終了時にいちばん大きい油の面積（mm²）です。成長点・段階ボーナス・ALL IN ONE・レンゲ回避点・サイズボーナス・FEVER・コンボは廃止しました。

| 項目 | 内容 |
| --- | --- |
| 面積の計算 | 落ち着いた粒数 × 粒 1 個の面積（約 6.57 mm²）。スープ面を直径 18cm とみなして換算しています |
| 落ち着いた粒数 | まとまった状態が 0.5 秒続いて初めて、大きくなったと数えます。小さくなったときはすぐ反映します |
| 赤い油 | 8 粒以上の油に取り込むと、その油と同じ粒数が外周に約 1.5 秒かけて足され、2 倍になります。赤い油 1 個につき 1 回だけです |
| 金の油 | 8 粒以上の油に取り込むと、残り時間が 3 秒増えます |
| レンゲ | 円の中に残った粒の分だけ面積が減ります。避けても加点はありません |
| BALL / BIG BALL / GIANT / MONSTER | いちばん大きい油の直径が 14mm / 26mm / 40mm / 55mm を超えたときに出る節目の表示です。点数は入りません |

補足は次のとおりです。

- 箸の前に一時的に寄っただけの塊は、0.5 秒まとまり続けない限り面積に数えません
- 赤い油は、育ててから取るほど増える量が大きくなります。すぐ取って確実に倍にするか、油が大きくなるまで待つかは、残り時間と消えるまでの猶予を見て判断します
- 粒の上限（`oil.maxDrops` = 1,800）に達すると、足せる分だけが増えます。このとき表示は「丼がいっぱい」になります
- 湧き出しの上限（`spawn.cap` = 700）は、いちばん大きい油に入っていない粒の数で判定します。大きく育てたあとも新しい油が湧き続けます
- 結果画面には LAST OIL（終了時のいちばん大きい油の直径と節目の名前）/ DOUBLED（赤い油で 2 倍にした回数）/ SPOON DODGED（レンゲを避けた回数 / 予告された回数）/ BEST が出ます

### ランク

| ランク | 必要スコア（mm²） | 称号 |
| --- | --- | --- |
| SS | 3,500 | GREASE GOD / 油の神 |
| S | 2,000 | FAT CAT / 背脂長者 |
| A | 1,000 | SLICK / 油職人 |
| B | 300 | GREASY / 背脂見習い |
| C | 0 | WATERY / ただの浮き油 |

閾値は自動プレイでの計測値を目安に決めています（面積 mm²。操作ごとに 1〜6 回の計測結果で、回によって上下します）。

| 操作のしかた | スコアの目安 |
| --- | --- |
| 箸を振り回す | 約 30 |
| 素早く動かしては止める | 約 40 |
| 何もしない | 約 50 |
| ゆっくり適当に動かす | 90〜220 |
| 油を 1 つずつ狙って寄せる（レンゲは避けない） | 160〜490（途中の最大は 420〜780） |
| 狙って寄せ、レンゲも避け、赤い油をすぐ取る | 1,490〜3,110 |
| 同上で、赤い油を消える直前まで待って取る | 1,190〜2,700 |

時間が進むほど油が湧く間隔が短くなり、レンゲの予告時間も短くなります。何回遊んでも開始時の条件は同じです。

## データの保存

| キー | 保存先 | 内容 |
| --- | --- | --- |
| `aburaBestArea` | localStorage | ベストスコア（面積 mm²。ブラウザを閉じても残る） |

得点の単位を面積（mm²）に変えたため、以前のキー `aburaBestScore` / `aburaBestScore2` の記録は使っていません。ベストスコアを消したい場合は、ブラウザの開発者ツールで `localStorage.removeItem('aburaBestArea')` を実行してください。

### 物理エンジン（vendor/liquidfun）について

npm パッケージ [liquidfun-wasm](https://www.npmjs.com/package/liquidfun-wasm) 7.0.0（Alex Birch 氏による Box2D / LiquidFun の WebAssembly 版、Zlib ライセンス）の `dist/umd/Box2D.js` と `dist/umd/Box2D.wasm` を使っています。

`Box2D.wasm.js` は、`index.html` をファイルとして直接開いても読み込めるように、`Box2D.wasm` を base64 の文字列にして JavaScript の変数に入れたものです。パッケージを入れ替える場合は、次の手順で作り直します。

```bash
npm pack liquidfun-wasm@7.0.0 && tar xzf liquidfun-wasm-7.0.0.tgz
```

```bash
cp package/dist/umd/Box2D.js vendor/liquidfun/Box2D.js
```

```bash
printf 'window.LIQUIDFUN_WASM_B64="%s";\n' "$(base64 < package/dist/umd/Box2D.wasm | tr -d '\n')" > vendor/liquidfun/Box2D.wasm.js
```

ゲーム内での役割分担は次のとおりです。

| 対象 | エンジン内での扱い |
| --- | --- |
| 油の粒 | 流体パーティクル（表面張力と粘性あり）。圧力・粘性・表面張力・衝突をエンジンが計算する |
| 箸 | カーソルに合わせて動かす剛体。スープに浸かっている 260（盤面座標）の範囲だけが油に当たる |
| ネギ・メンマ・麺の端 | スープに浮かぶ剛体 |
| 丼の縁 | 円周に沿って並べた固定の板 |

スープ自体の流れ（箸でかき回したときの流れ）と波紋は、従来どおり `index.html` 内の格子計算で求め、油の粒と具をその流れに乗せています。

### index.html の中身

スクリプトはおおよそ次の順で並んでいます。

| セクション | 内容 |
| --- | --- |
| 調整パラメータ（`TUNE`） | 制限時間、油の物理、箸、レンゲ、得点まわり、湧き出し、ランク閾値 |
| 背景 | 丼・スープ・具材を起動時に 1 回だけ描画 |
| 波・スープの流れ | 波紋のシミュレーションと簡易流体 |
| 油の粒子 | 粒の大きさ、近傍探索、メタボール（密度場）による描画 |
| WebGL | 1 パス目でスープ面と油、2 パス目で重ね合わせと弱い色調整 |
| 物理エンジン | LiquidFun の初期化、粒の生成と削除、エンジン内の粒とゲーム側の情報の対応づけ |
| ゲーム状態 | スコア（いちばん大きい油の面積）、ベストの保存処理 |
| サウンド | Web Audio API で効果音と BGM を生成（音声ファイルは使用していない） |
| 合体・分裂判定と面積 | 連結成分を追跡して合体・分裂を判定し、落ち着いた大きさ（`settleSizes`）と赤い油の 2 倍化（`special` / `growDoubling`）を処理 |
| 妨害具・レンゲ | ネギ・メンマ・麺の端の出現と、レンゲのすくい上げ |
| 進行・描画・入力 | 時間経過、節目の表示、スコア更新、結果画面、HUD 描画、ポインター / キーボード入力、一時停止 |

## 調整のしかた

ゲームバランスを変えるときは、`index.html` 冒頭の `TUNE` オブジェクトを書き換えます。主な項目は次のとおりです。

| 項目 | 現在値 | 効果 |
| --- | --- | --- |
| `round.time` | `60` | 制限時間（秒） |
| `round.ready` | `1.4` | START から時間が進み始めるまでの合図の秒数 |
| `oil.tension` / `oil.tensionN` | `.2` / `.2` | 表面張力。大きいほど油が丸くまとまり、ちぎれにくい |
| `oil.visc` | `.25` | 粘性。大きいほどとろみが出て飛び散りにくい |
| `oil.flowK` | `7` | スープの流れへの追従。大きいほど油が早く止まる |
| `stick.liftSpeed` | `800` | 箸がこの速さ（盤面座標 / 秒）を超えるとスープから浮く |
| `stick.dipSpeed` / `stick.dipDelay` | `650` / `.08` | この速さを下回った状態がこの秒数続くと、箸がスープに戻る |
| `stick.close` | `8` | 箸が閉じる速さ。大きすぎると挟んだ油がちぎれる |
| `spoon.warn` / `spoon.warnMin` | `2.4` / `1.8` | レンゲの予告からすくうまでの秒数（開始時 / 下限） |
| `spoon.lastStart` | `7` | 残り時間がこの秒数を切ったら、新しいレンゲの予告を出さない |
| `score.growHold` | `.5` | まとまった状態がこの秒数続いたら「大きくなった」と数える |
| `score.doubleTime` | `1.5` | 赤い油で 2 倍にふくらむのにかける秒数の目安 |
| `score.popMin` | `20` | この mm² 以上増えたときだけ、盤面に増加分の数字を出す |
| `score.tiers` | — | 節目の表示の直径（mm）と名前（点数はなし） |
| `score.goldTime` | `3` | 金の油で延びる秒数 |
| `oil.maxDrops` | `1800` | 粒の絶対上限。赤い油で 2 倍にふくらむ分も、ここで頭打ちになる |
| `spawn.cap` | `700` | いちばん大きい油に入っていない粒がこの数に達したら、湧き出しを止める |
| `grades` | — | ランクの閾値（mm²）と称号 |

盤面は内部的に 1000×1000 の座標系で計算しており、スープ面の直径を 18cm とみなして mm 表示に換算しています。物理エンジンには、この座標を 100 で割った値（メートル扱い）を渡しています。
