# FAT CHANCE / あぶらあつめ

ラーメンのスープに浮いた油を、箸で寄せてひとつにまとめるブラウザゲームです。制限時間 60 秒のスコアアタック形式で、`index.html` 1 ファイルだけで動きます。

## 動かし方

ビルドや依存パッケージのインストールは不要です。`index.html` をブラウザで開けば遊べます。

ローカルサーバー経由で開く場合は、リポジトリ直下で次のコマンドを実行し、`http://localhost:8765` にアクセスします。

```bash
python3 -m http.server 8765
```

MAMP の htdocs 配下に置いているので、MAMP を起動している場合はそのまま MAMP の URL からも開けます。Claude Code の desktop アプリでは `.claude/launch.json` の `abura` 設定で同じサーバーを起動できます。

### 動作環境

- WebGL2 に対応したブラウザ（最新の Chrome / Safari / Firefox / Edge）
- WebGL2 が使えない環境では Canvas 2D の簡易描画に切り替わります（フィルム風の後処理などは省略）
- PC（マウス・キーボード）とスマートフォン（タッチ）の両方に対応
- フォント（Archivo Black）は Google Fonts から読み込みます。オフラインでは代替フォントで表示されます

## 遊び方

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| 箸を動かす | マウス移動 | 盤面をドラッグ |
| 箸を開く / 閉じる | クリックかスペースを押している間だけ開き、離すと閉じる | 右下の OPEN ボタンを押している間だけ開く |
| ゲーム開始 | START ボタン / Enter | START ボタン |
| リトライ | RETRY ボタン / R / Enter | RETRY ボタン |
| サウンド ON/OFF | 右下のスピーカーボタン | 同左 |

### ルール

- 得点になるのは、箸で直接触れて寄せた油どうしの合体だけです。箸が関わらずに自然にくっついた分は 0 点です
- 大きい油どうしの合体ほど高得点になります
- ゆっくり寄せた合体を続けるとコンボ倍率が上がります（最大 ×5.0）
- 箸を速く振ると油が割れます。勢いよくぶつけると油が跳ねて減ります
- ネギ・メンマ・麺の端に当たった油も割れます
- 赤いラー油を取り込むと 7 秒間の FEVER（得点 2 倍・油が大量に湧く）、金色の油を取り込むと残り時間が 2 秒増えます
- 大きな油ができるとレンゲがすくいに来ます。WARNING が出たら最大の油を逃がしてください。逃がしきると加点されます
- 盤面の油をひとつにまとめると「ALL IN ONE」として大きなボーナスが入ります

### スコアとランク

最終スコアは「合体などで得た点数」と「最大の油の直径 × 60 点（サイズボーナス）」の合計です。

| ランク | 必要スコア | 称号 |
| --- | --- | --- |
| SS | 32,000 | GREASE GOD / 油の神 |
| S | 20,000 | FAT CAT / 背脂長者 |
| A | 12,000 | SLICK / 油職人 |
| B | 6,000 | GREASY / 背脂見習い |
| C | 0 | WATERY / ただの浮き油 |

油の直径が 14mm / 26mm / 40mm / 55mm を超えると、それぞれ BALL / BIG BALL / GIANT / MONSTER の段階ボーナスが入ります。

### ラウンドと難易度

同じタブで続けて遊ぶとラウンド数が増え、ラウンドごとに油の引き合う力が弱まり、割れやすくなります（9 ラウンド目で上限）。ラウンド数はタブを閉じるとリセットされます。

## データの保存

| キー | 保存先 | 内容 |
| --- | --- | --- |
| `aburaBestScore` | localStorage | ベストスコア（ブラウザを閉じても残る） |
| `aburaPlayed` | sessionStorage | このタブでのプレイ回数（ラウンド数の計算に使用） |

ベストスコアを消したい場合は、ブラウザの開発者ツールで `localStorage.removeItem('aburaBestScore')` を実行してください。

### index.html の中身

スクリプトはおおよそ次の順で並んでいます。

| セクション | 内容 |
| --- | --- |
| 調整パラメータ（`TUNE`） | 制限時間、油の物理、割れやすさ、得点、湧き出し間隔、ランク閾値 |
| 背景 | 丼・スープ・具材を起動時に 1 回だけ描画 |
| 波・スープの流れ | 波紋のシミュレーションと簡易流体 |
| 油の粒子 | 油の玉を粒子の連結体として扱い、メタボール（密度場）で描画 |
| WebGL | 1 パス目でスープ面と油、2 パス目で色収差・グレイン・周辺減光などの後処理 |
| ゲーム状態 | スコア、コンボ、ラウンド、保存処理 |
| サウンド | Web Audio API で効果音と BGM を生成（音声ファイルは使用していない） |
| 合体・分裂判定 | 連結成分を追跡し、合体・分裂のイベントと得点を計算 |
| 妨害具・レンゲ | ネギ・メンマ・麺の端の出現と、レンゲのすくい上げ |
| 進行・描画・入力 | 時間経過、段階ボーナス、HUD 描画、ポインター / キーボード入力 |

## 調整のしかた

ゲームバランスを変えるときは、`index.html` 冒頭の `TUNE` オブジェクトだけを書き換えれば済むようにしています。主な項目は次のとおりです。

| 項目 | 例 | 効果 |
| --- | --- | --- |
| `round.time` | `60` | 制限時間（秒） |
| `oil.kCoh` | `1800` | 油が引き合う強さ。小さいほど箸でちぎれやすい |
| `oil.visc` | `18` | 粘性。大きいほどとろみが出て飛び散りにくい |
| `split.speed` | `1100` | この速さを超えた箸が触れると油が割れる |
| `score.assistWindow` | `1.5` | 箸で触れてから何秒以内の合体を得点対象にするか |
| `score.comboWindow` | `1.6` | コンボが途切れるまでの秒数 |
| `score.tiers` | — | 段階ボーナスの直径（mm）と点数 |
| `grades` | — | ランクの閾値と称号 |

盤面は内部的に 1000×1000 の座標系で計算しており、スープ面の直径を 18cm とみなして mm 表示に換算しています。
